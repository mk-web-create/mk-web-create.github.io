# 在庫・発注管理 業務改善デモ画像

このフォルダーの画像は、製造業向け「在庫・入出庫・発注管理システム」のローカル試作を実際に操作して取得した画面です。部品名・仕入先・数量はすべてデモ用の架空データです。

- `dashboard.png`: 在庫不足、発注候補、最近の入出庫
- `inventory.png`: 正常・注意・不足を表示する在庫一覧
- `outbound.png`: 出庫登録フォーム
- `candidates.png`: 推奨発注数と算出根拠を表示する発注候補
- `orders.png`: 発注予定から完了までを管理する発注管理
- `quick-title-poster.png`: クイック紹介動画の読み込み前に表示するタイトル画像

元画像は 1440 × 900 px です。画像を更新するときは、同じファイル名・同じ画面サイズで差し替えるとHTMLの変更は不要です。個人情報、実在企業の非公開データ、ローカル開発用URLのアドレスバーが写っていないことを確認してください。

動画は `assets/videos/` に配置しています。

- `demo_inventory_order_quick_title.mp4`: 制作事例一覧と詳細ページ冒頭で使う約21秒の紹介動画
- `demo_inventory_order.mp4`: 詳細ページの `id="demo-media"` で使う約82秒の操作動画

動画を更新するときは、同じファイル名・16:9のMP4で差し替えるとHTMLの変更は不要です。将来、公開デモURLを追加する場合は `works/inventory-order-demo.html` の `id="demo-media"` 付近へ導線を追加し、ローカル開発用URLは掲載しないでください。
