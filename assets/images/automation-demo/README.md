# 業務改善デモ用画像

現在のトップページは画像がなくても崩れない構成です。実際の操作画面を追加する場合は、個人情報・購入履歴・非公開URLなどが写っていないことを確認し、次の名前でこのフォルダーへ配置してください。

- `excel-url-input.webp`: `product_urls.xlsx` に商品URLを入力している画面
- `powerpoint-output.webp`: 自動生成されたPowerPointの代表ページ
- `before-after.webp`: 手作業と自動生成後の違いが伝わる比較画像（任意）

推奨サイズは横1200px以上、16:9前後、WebP形式です。画像を掲載するときは、トップページの「商品URLから提案資料を自動生成」カード内へ追加します。
